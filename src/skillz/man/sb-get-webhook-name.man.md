# sb-get-webhook-name

Fetch and print the name of the Discord webhook configured for the given agent.

## USAGE

`sb-get-webhook-name <agent-handle>`

## EXAMPLES

1. `sb-get-webhook-name aiden`
1. `sb-get-webhook-name walt`
